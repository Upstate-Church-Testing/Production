# Software logos

Shown beside each piece of software on Gear › Software so it's clear what you're
looking at. Each comes from the maker's own published artwork:

- `propresenter.svg`: the mark from Renewed Vision's ProPresenter logo on renewedvision.com, cropped to the mark.
- `companion.png`: Bitfocus Companion's product icon from bitfocus.io, scaled to 128 px.
- `blackmagic.svg`: the three squares from Blackmagic Design's logo on blackmagicdesign.com, cropped to them.
- `apple.svg`: the Apple mark from Simple Icons (simpleicons.org), for macOS and iPadOS.

To add one, drop the file here and set `software.logo` to its file name.
